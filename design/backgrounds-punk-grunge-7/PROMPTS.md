# Prompt Set

执行模式：Codex 内置 `image_gen`。输入图作为编辑目标（第一张）或视觉风格与色板参考（其余六张）。

## 统一主提示

制作 1672:941 的全屏网站背景。延续黑色朋克杂志、地下活动海报和街头粘贴墙的视觉语言，增强复印颗粒、褪色油墨、纸张纤维、刮擦、胶痕、撕纸接缝、粉笔划痕、喷漆微点和小型涂鸦残迹。中央 72%–76% 保持安静、深色和开放；更强的装饰集中在画布外侧 10%–15%。色板以黑色为主，搭配脏白、电紫和安全橙。

## 统一限制

不得出现文字、字母、数字、Logo、图标、按钮、人物、主体物、大型插画、中心图案、大面积棋盘格、巨型箭头、壁画、成片亮色或重复壁纸图案。单个彩色碎片不超过画布约 4%–7%，不可影响后续叠加内容。

## 六张变体方向

1. 左上与右下的新闻纸碎片、窄撕边和小型半调网点。
2. 顶部与底部的撕纸层、透明胶带影和粘贴考古痕迹。
3. 紫色占比稍高的边缘碎片、裂墨和订书孔。
4. 橙色占比稍高的磨损、干滚筒痕和喷点。
5. 左右边缘为主、上下更稀疏的低干扰版本。
6. 四角不对称碎片、小型手绘残迹和大间隔留白。
