# Punk Grunge 网页背景（7 张）

全部图片为 1672 × 941 横版 PNG，中央约 72%–76% 保持黑色负空间，方便继续叠加标题、Logo、按钮、卡片和人物。

- `01-enhanced-original.png`：在原底图基础上强化做旧、复印颗粒和边缘涂鸦。
- `02-torn-newsprint-corners.png`：左上、右下碎纸与半调网点。
- `03-tape-paste-archaeology.png`：撕纸层、胶带和粘贴残迹更明显。
- `04-purple-edge-collage.png`：紫色碎片占比稍高，中央克制。
- `05-orange-abrasion.png`：橙色磨损和喷点作为主要边缘节奏。
- `06-side-edge-minimal.png`：装饰主要集中在左右两侧，最适合长文案。
- `07-four-corner-graffiti.png`：四角小型涂鸦和碎片分布。

统一限制：无文字、数字、Logo、按钮、人物、居中图案或大面积棋盘格；彩色碎片集中在边缘，单个元素不超过画布约 4%–7%。
